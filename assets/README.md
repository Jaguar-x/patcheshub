# Asset library

`source/brand/` holds the unmodified logo originals. These are not publicly served.

Website-ready assets belong under `public/assets/`:
- `brand/`: approved logos and marks
- `products/patches/`, `pins/`, `coins/`, `keychains/`: product images
- `editorial/`: homepage and storytelling compositions

Use lowercase descriptive names, such as `pvc-patch-detail-navy.webp`.
Keep original artwork outside `public/`. Export web assets as WebP or AVIF where appropriate.
Record generated images and usage in `docs/asset-register.md`. Do not present concept imagery as completed customer work.
